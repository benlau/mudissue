Enable tab completion for `mud` commands and options by adding this line to your shell rc file:

**Zsh** (`~/.zshrc`, or `~/.zprofile` on macOS):

```bash
source <(mud completion)
```

**Bash** (`~/.bashrc`, or `~/.bash_profile` on macOS):

```bash
source <(mud completion)
```

Reload your shell (e.g. `source ~/.zshrc`) or open a new terminal for completion to take effect.
